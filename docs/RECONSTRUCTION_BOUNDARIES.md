# 再現対象・同一性・保証範囲

## 主語の固定

| 対象 | 定義 | 判断境界 |
|---|---|---|
| `HISTORICAL_MARS` | 国鉄・JR側が開発・運用した実在のMARS各世代 | 史料が直接支持するものだけを実装事実として扱う |
| `RECONSTRUCTION_SPEC` | 公開資料から抽出した要求・アルゴリズム・制御・状態遷移の記述 | 史料と推論を分ける |
| `LOGICAL_EXPERIMENT` | 再構成した仕様を現代の環境で動かす部分モデル | 動作の一致は実機の言語・装置・性能の一致を含意しない |
| `LANGUAGE_COMPARISON` | 同一検証契約を複数言語・処理系に実装して比較する実験 | 史料の忠実な復元とは別の評価軸 |

## 世代の識別

| 世代 | 公開資料で確認できる代表的変化 | 未確認・持ち越し禁止 |
|---|---|---|
| MARS-1（1960） | 専用回路による座席予約の自動化 | 後継機のプログラム言語を遡及適用しない |
| MARS-101（1964） | プログラム内蔵方式、SC/TC/FCの役割分担、区間別座席ファイル、二重照合、自動発券。40ビット語と命令構造の一部は原著に記載 | 原機の原ソース・**完全な**命令セットとアセンブラ表現、正確な座席割当規則、通信符号体系 |
| MARS-105（1972～1974に段階移行・増強） | 業務拡張に応じて専用ハードウェア依存からソフトウェア主体の構成へ転換。1972年に初期切替、1973年1月まで段階移行、以後増強 | 101と全アルゴリズム・言語が同一との推定、初切替と全面移行の同一視 |
| MARS-301（1985） | CCS通信、SRS在庫、DMSデータ管理など旅客販売総合システム化 | 現行世代の内部実装との同一視 |
| MARS-501（2004） | IP化、Web連携、複数基盤の運用、COBOL業務ロジックを含む | 全サブシステムがCOBOLとの断定 |
| MARS-505（2020） | インターネット販売・チケットレス等に対応して機能拡張 | 現行の言語構成・ソースコード・トランザクション方式の断定 |

日付と事実の根拠は [SOURCE_REGISTER.md](SOURCE_REGISTER.md)、出典間の齟齬は [史料総合監査](research/HISTORICAL_ENGINEERING_AUDIT_2026-11-09.md) を参照。MARS-105の1972年からの段階切替は1974年の日立評論（S30）で確認し、1973年の全面移行期と区別する。実機と本実験の同一性を「何割再現した」等の恣意的な合算で表現しない。

## MARS-101 初期実験の対応表

| 原設計の観測 | 本実験 | 判定 |
|---|---|---|
| 列車・乗降駅の表引き（TC） | 架空の駅名から区間番号への変換 | `DERIVED` |
| 区間別座席状態のビットパターン（FC） | 区間ごとのビット占有情報と全区間の OR 照合 | `DERIVED` |
| 車両・座席の選択、ファイル訂正（FC） | 空席の先頭から選択、更新 | `SURROGATE`：正確な優先順位は不明 |
| 二系統の独立処理・照合 | 同じ要求を二つのレーンで実行し状態と出力を比較 | `DERIVED`：タイミング・故障切替は別 |
| 要求と回答の記録・復旧 | ハッシュ連鎖イベント・JSON保存・全件再生 | `SURROGATE`：磁気テープ形式・復旧手順ではない |
| 端局装置の送受信 | JSONで要求と結果を交換 | `SURROGATE`：20/26レターの符号は未再現 |
| 複数同時要求の処理 | 書込ロックで安全に直列化 | `SURROGATE`：原機の並列パイプラインを再現しない |
| 発券 | 架空番号・架空金額・実券ではない文字列 | `SURROGATE`：本物の券面・運賃制度とは無関係 |

`DOCUMENTED` は論文で直接確認できた構造に対するラベルであり、モデルの再現達成度は別判定。MARS-101原機の実装言語はこの段階では `UNKNOWN`。

## 次に固定すべき観測

1. HITAC-3030の**完全な**命令セット・プログラム表現・アセンブラの資料（40ビット語・命令の一部はS01/S03に記載）。
2. 1964年の端局符号表・通信回線制御・異常時再送条件。
3. FCの座席優先順位、区間管理、取消、重複発売防止の正確な処理条件。
4. 二重照合で不一致となった場合の停止・切替・再同期の境界。
5. 当時の総合試験仕様・合否判定・実績値。

取得不能な情報は `UNKNOWN` のまま保持し、実験上の代用を原設計へ遡及させない。
