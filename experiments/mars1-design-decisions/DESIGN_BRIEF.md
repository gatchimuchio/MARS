# MARS-1 制約付き独立設計問題（解答を示さない版）

## 目的

1960年前後の工学的制約で、複数窓口からの座席予約を安全に処理する系を構想する。
**実在MARS-1の方式を当てるゲームではない**。各判断について、採用条件・不採用理由・反証条件を残す。

## 開示する要求と制約

| 項目 | 与件 | 証拠・限定 |
|---|---|---|
| 同時代の営業対象 | 4列車、15日先まで、1日最大3,600席、1列車最大900席、3区間 | S17 PDF p.2 の装置仕様。これは全業務一般の上限ではない |
| 操作 | 照会、予約、指定予約、解約、印字、再送の区別 | S17 PDF p.2–3 |
| 窓口通信 | 50ボー、情報伝送に1.7～2.6秒 | S17 PDF p.2。片道だけの時間とは解釈しない |
| 処理目標 | 全処理3秒以内、中央処理平均約0.1秒 | S17 PDF p.2 の既存機報告値。独立設計側の比較目標として開示する |
| 利用可能な記憶の例 | 磁気ドラム3,000rpm、200トラック、400,000ビット | S17 PDF p.6。当時の実装実績を制約例として使用 |
| 電子回路の速さの目安 | 約100kcのクロック | S17 PDF p.4。別方式が同じ命令性能を得るとは仮定しない |
| 安全 | 二重販売禁止、障害時の無条件販売継続禁止 | 原資料の冗長照合と業務停止の重大性からの要求抽出。詳細な故障率は不明 |

## 課題

1. 利用者の入力、通信、記憶、検索、予約確定、印字、記録、復旧の機能境界を提案する。
2. 少なくとも2方式を独立に設計する。媒体配置・電子部品の規模・処理時間・保守性・改正耐性を比較する。
3. すべての設計変数に、一次史料の値、演繹された値、実験仮定、未確認を標識する。
4. 想定外入力、予約競合、媒体故障、片系不一致について停止・隔離・再開の条件を記述する。
5. **設計案と評価基準を先に固定**してから、[実在MARS-1原著](https://www.hitachihyoron.com/jp/pdf/1961/ex39/1961_ex_39_09.pdf)の実構造と突合する。

## 結果の受入条件

- 原機と同じ案を選んだかどうかは正解判定に用いない。
- 成立しない案は、その理由が検証可能なら有意な結果とする。
- 当時の部品点数、実際の単価、故障率、完全な信号手順は未取得。これらを実測値として捏造しない。
- 本リポジトリの比較プログラムは、**すでに原著を参照した研究者による原著着想の模型**であり、この設計課題を独立盲検で解いた結果とはみなさない。
- 外部参加者が独立に取り組む場合、元の回答・作成時点・閲覧済み資料・使用したモデルを記録し、後で回答を書き換えない。
