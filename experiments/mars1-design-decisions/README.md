# MARS-1 制約付き設計と不採用案の比較実験

**対象：`LOGICAL_EXPERIMENT` / `SURROGATE`。MARS-1実機のソース・回路・速度を再現したものではない。**

この実験は、1961年原著の設計条件を「回転媒体の物理的なアクセス順」としてモデル化し、同じ予約契約を満たす3つの配置・探索方式を比較する。主目的は、**当時の技術選択を支配する制約・因果を可視化すること**であり、処理速度の競争や原機の完全復元ではない。

## 実行

```bash
python3 experiments/mars1-design-decisions/design_lab.py geometry
python3 experiments/mars1-design-decisions/design_lab.py run --summary
python3 experiments/mars1-design-decisions/design_lab.py run --seed 1960 --requests 60 --occupied-prefix 450
python3 -m unittest discover -s experiments/mars1-design-decisions/tests -v
```

- Python標準ライブラリのみ。実鉄道・予約システムへの接続なし。出力は架空の座席IDと検証用ハッシュのみ。
- `run` は完全なJSON（原典値、導出値、全仮定、結果）を標準出力する。固定したシードと件数で再実行できる。
- `--occupied-prefix` は、**実験上の座席優先順位**の先頭から何席を既売にするか（0～900）。現実の稼働率ではない。
- 3方式の入力予約列、物理位相、座席優先順位、在庫初期状態は同一。**売れた座席・拒否結果・最終状態のハッシュが一致しなければ実験を失敗させる**。

## 比較する3方式

| 方式 | データ配置・アクセスの代用 | 時間が増える条件 | 原機との同一性 |
|---|---|---|---|
| `phase_aligned_parallel` | 優先度順の座席ビット列を各区間の同位相トラックへ置き、要求した区間を同時走査 | 対象領域開始待ちと、最初の空席の位置 | 原著の優先度配列・ドラム利用から着想。区間同時読みは**未証明の仮定** |
| `section_by_section` | 同じ優先度順データを区間ごとに1回全件走査して合成 | 要求区間数、回転待ち | 不採用案を想定した`SURROGATE`。実機の方式ではない |
| `seat_id_random_access` | ドラムを座席ID順に置き、優先度順候補をその都度参照 | 優先順位と実アドレスの食い違い、回転待ち | 不採用案を想定した`SURROGATE`。実機の方式ではない |

すべて同じ区間占有ビットに対する予約条件を満たす。**時間差は「物理媒体とデータ並び方の関係」を条件付きで測った結果**であり、電子回路数・経済性・制御方式の優劣を直接測定したものではない。

## 検証境界

- 磁気ドラムの周長2,000ビット、毎秒100,000ビットの読み出しは、S17 p.6の数値から計算した**派生値**。実信号の正確なビットタイミングは未確認。
- 3区間を同位相の別トラックへ置く割当は実験仮定。原論文の記憶配置図との完全一致を主張しない。
- 1レコード1,000ビット、最大900席を想定。実機の付加情報、座席間隔、乗継・発券の詳細は未再現。
- `phase_aligned_parallel` は複数ヘッドの同時利用に相当する。必要部品数・実行可否は未確定なので、**これを当時最適・最安価とは判定しない**。
- 検索時間に、電子回路の全遅延、整合照合、通信交換、再送、キュー、印字、故障停止を含めない。原著の中央処理平均0.1秒と同じ測定量ではない。
- 50ボー回線の伝送時間は原著1.7～2.6秒。出力の「伝送時間の中点を加算した値」は説明用の算術であり、当時の総処理時間の推定値でも実績でもない。
- 独立盲検設計は未実施。対象を知らない参加者向けに[設計課題](DESIGN_BRIEF.md)を分離している。
